# 可重用餘料庫：後備功能規劃

**狀態：只記錄構想，暫不實作。** 本文件保留日後評估之用；不代表目前應加入功能、介面或資料格式。實作前應先確認工作流程、使用條件及當時系統設計仍然合適。

## 為甚麼保留這個構想

大型板材切割後留下的完整板塊，可能適合下一次工作使用。若不同工作分開幾次開料，系統將來可先找尺寸合適的已存餘料，再考慮使用新板，減少浪費，亦避免把有用餘料遺忘在一旁。

這是**跨工作、跨開料時段的實物庫存**概念，與目前單次排料結果中顯示餘料尺寸或 R 編號不同：畫面上算出的餘料不會自動成為實際庫存。

## 實物工作流程是核心

1. 每塊實際保存的餘料都要有獨立、可辨認的 R 編號，例如 `R1`、`R2`；編號要與實物一一對應，並在板上用粉筆或合適方式標記尺寸。
2. 把已標記的餘料集中存放，方便日後按編號、尺寸及材料核對。
3. 只有在實際鋸切完成、實物已量度並確認可以保存後，才可加入餘料庫。計算結果、預計會留下的材料、未完成回放的材料、鋸屑或不適合保存的碎料，一律不應自動入庫。
4. 日後使用餘料時，須能把系統所選的 R 編號與現場那塊實物核對；如尺寸、材料或狀況不符，應可略過或修正，不能假設庫存紀錄永遠準確。

## 將來若實作，可先評估的方向

- 功能應為**可選**，並清楚說明用途及操作責任；未需要管理實物庫存的使用者，不應被迫輸入、整理或維護餘料資料。
- 啟用後，可在新工作排料前，從已確認的餘料中尋找能容納部件的板塊；合適時優先考慮使用餘料，再使用新板。系統需清楚列出用了哪些 R 編號及尺寸，讓使用者能在開工前按實物核對。
- 餘料紀錄應以單塊實物為單位，而不是只記一種尺寸的總數。日後可按需要評估是否記錄材料／厚度、量度尺寸、狀況、來源工作及在庫／已使用狀態；不要在未有明確需要前把資料模型做得過重。
- 「排料建議使用某塊餘料」與「師傅已實際用掉該塊餘料」是兩回事。只有經使用者確認實際用料後，才更新其庫存狀態，避免取消、未完成或改方案時錯誤扣除。
- 先評估尺寸門檻、尺寸容差、方向限制、材料相容性、修邊和鋸縫等條件；不可只憑外框尺寸相近，就聲稱餘料一定可用。
- 若儲存或匯出工程資料，日後須考慮舊工程兼容、備份、重複 R 編號及跨工程識別；R 編號需有明確範圍，避免不同工程各有 `R1` 卻令實物混淆。

## 使用者理解與風險

逐塊標記、量度、集中存放及更新狀態都需要額外工夫。庫存量一多，若操作步驟不清楚，可能出現拿錯板、重複登記、實物已用但紀錄仍在，或系統推薦了現場找不到的餘料。因此實作前應確認目標使用者確有管理餘料的需求，並用簡單流程解釋：**先實物標記及確認，再加入庫存；使用前核對 R 編號及尺寸；實際用料後才更新狀態。**

任何庫存紀錄或排料結果都不能代替師傅檢查實物、材料狀況、切割可行性及機台安全。

## 暫緩原則

目前只保留此構想，不改現有排料邏輯、計算結果、資料格式、設定或使用介面，也不把任何模擬餘料寫入庫存。待使用條件成熟、工作流程更明確，或未來有更合適的系統／電腦使用情境時，再由使用者決定是否委託 AI 或開發者整合；實作者應先閱讀本文件並重新核對當時的程式與需求，不要把這份規劃當成已批准的實作規格。
