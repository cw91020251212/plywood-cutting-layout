# CutNest — GitHub project name for 木材切割排版｜夾板簡易排料

The software display name remains **木材切割排版｜夾板簡易排料**. **CutNest** is only the English GitHub/project name used for publishing and sharing. It helps plan sheet cuts, compare verified candidate layouts, and reduce material waste.

## Highlights

- Metric and imperial dimensions
- Plywood parts, sheets, kerf and edge-trim settings
- Candidate layout validation and cut-by-cut details
- Save/load project JSON and print reports
- Offline-ready service worker and installable app icon

## Live app

https://cw91020251212.github.io/cutting_optimizer_v5_auto/

## Notes

The output is a candidate layout for practical checking. An experienced woodworker should verify the actual sheet, tools, supports and machine safety before cutting.
